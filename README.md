# Iranopasmigirim-IOCs
This Repository contains complementary IOC references in the blog post under https://labs.infoguard.ch/

- The file `file_indicators` contains all files that are part of the blogpost, including all inactive and test files.
- The file `network_indicators` contains alls found network indicators, such as all GitHub Repositories and all `tmpfile`/`curl-t` staging servers
- The file `parsastealer_exfil_files` contains an overview of all exfiltrated files by ParsaStealer listed per Generation
- The file `parsastealer_config_decryption` can be used to decrypt the config and list all exfiltrated files, telegram configuration and used host fingerprinting URLs
